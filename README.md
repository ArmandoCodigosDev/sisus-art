# 🎨 Sisus Art

Aplicación móvil educativa de arte y dibujo guiada por **Mamá**, una gatita tranquila y serena que acompaña al usuario paso a paso en sus lecciones de acuarela, óleo y acrílico.

## 👥 Equipo: Wisin y Yandel
* **Kristell Nahomi Monjardin Gamez** – Diseño UI/UX, Arte y Modelado de Datos
* **Cesar Armando Lopez Navarro** – Arquitectura, Backend y Control de Versiones

## 🛠️ Stack Tecnológico
* **Backend:** C# / ASP.NET Core Web API + SQLite + Dapper + JWT
* **Frontend:** React Native / Expo Router (TypeScript)

## 📁 Estructura del Proyecto
* \`/Backend\` – API REST, modelos de dominio, acceso a datos y autenticación.
* \`/Frontend\` – Aplicación móvil multiplataforma.
